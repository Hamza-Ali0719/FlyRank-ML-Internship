| # | Task Description | Classification | Rationale |

| 2 | Writing LinkedIn posts about internships | **Delegate to AI with Review** | AI drafts, I personalize the tone and add specific project stats. |
| 3 | Data cleaning (pandas) | **Delegate to AI with Review** | AI writes the code; I check the data distribution to ensure it's correct. |

| 6 | Creating weekly to-do lists | **Fully Automate** | AI pulls calendar priorities and generates a daily plan. |
| 7 | Reviewing code before git push | **Just Me** | AI misses logical business errors (e.g., wrong column names). |
| 8 | Searching for scholarships/internships | **Fully Automate** | AI scrapes job boards and sends me filtered alerts daily. |
| 9 | Writing emails to recruiters | **Delegate to AI with Review** | AI drafts a professional reply; I proofread for specific details. |
| 10 | Taking university lecture notes | **Collaborate with AI** | AI transcribes; I manually highlight exam-relevant topics. |
| 11 | Setting up Python environments | **Fully Automate** | A shell script handles `pip install -r requirements.txt` automatically. |
| 12 | Choosing which ML model to use | **Collaborate with AI** | AI suggests options, I decide based on dataset size and interpretability. |
| 13 | Writing README.md documentation | **Delegate to AI with Review** | AI writes structure; I fill in specific numbers (accuracy, F1). |
| 14 | Managing assignment deadlines | **Fully Automate** | AI calendar sends push notifications for upcoming submissions. |
