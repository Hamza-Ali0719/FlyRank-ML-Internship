Predicting Content Engagement

A Machine Learning Study on 79M+ Rows of Production Content Data

Author: Hamza Ali · FlyRank ML Internship · Q3 2025

📄 Abstract

Question: Can we predict content engagement (90-day clicks) using content metadata and search signals from production logs?

Method: We trained a Random Forest regressor on 79M+ content performance records, using features including impressions, CTR, content age, word count, and search volume.

Result: The model achieved an R² of 0.XX and Spearman correlation of 0.XX, with impressions and CTR as the strongest predictors.

Implication: This work provides a decision-support tool for prioritizing content refresh actions.

Contribution: A reproducible, publicly-deployed research paper built on real production data.

1. Introduction

Content teams need to decide which pieces to refresh, update, or leave alone. Understanding what drives engagement helps prioritize these decisions.

This study investigates: How accurately can we predict content engagement (90-day clicks) using metadata and search signals from FlyRank's production dataset?

2. Data

Release: FlyRank Q3 2025 Production Data

Table: content_refresh_anonymized.csv

Date Window: 2025-07-01 to 2025-09-30

Exclusions:

  • Rows with missing clicks_90d
  • Content with < 50 impressions
  • Content less than 30 days old
  • Internal test traffic

Public-Safe: No client names, URLs, or private queries appear in this paper.

5. Limitations & Honest Framing

What This Work Cannot Claim:

  • Causality — observational data only
  • Generalization to other content types or search engines
  • No temporal validation (future work needed)
  • Label noise — clicks is a proxy for engagement
  • Limited feature set (~10 features)

Honest Framing: "The model provides observed patterns in content engagement. It is decision-support only and should be validated with A/B tests."
